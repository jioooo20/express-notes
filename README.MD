# My JavaScript Learning Journey

Welcome to my JavaScript learning journey! This repository documents my progress as I dive into the world of JavaScript, from the fundamentals to more advanced concepts. I'm excited to share what I learn and build along the way.

## Why I'm Learning JavaScript

I've always been fascinated by the power of the web to connect people and create amazing experiences. I believe that mastering JavaScript is the key to unlocking my potential as a developer and bringing my creative ideas to life. My goal is to build beautiful, interactive, and user-friendly web applications that can make a positive impact. I'm also keen to contribute to the open-source community that has given so much to developers like me.

## What I'm Building

This repository is a mono-repo that contains both the front-end and back-end of a project I'm working on as I learn.

-   **Front-end (`/fe`):** A simple, clean user interface built with HTML, CSS, and vanilla JavaScript.
-   **Back-end (`/be`):** A Node.js server using Express.js to serve data to the front-end.

## Technologies

-   **Languages:** JavaScript, HTML, CSS
-   **Front-end:** Vanilla JS (for now!)
-   **Back-end:** Node.js, Express.js
-   **Tools:** Git, VS Code
